# simple-chatgpt-plugin

Prototype ChatGPT integration for Simple Chile.

## Current phase

Build a grounded public-information source for the first plugin demo.

## Source data

`data/simple/` contains a versioned snapshot derived from public pages on https://simplechile.com/.

Current recovered sections:
- Nosotros
- Manifiesto
- Clientes
- Contacto

The source layer intentionally separates published facts from model inference. Additional pages/cases should be added only when discovered and verified.
